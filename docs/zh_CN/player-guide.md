# SimpMC-BedWars 玩家物品指南

保护本队的床，破坏其他队伍的床，并淘汰所有对手即可获胜。死亡瞬间床还在时，玩家会完成本次复活倒计时；床被破坏后再次死亡会被淘汰。

服务器可以调整商品、价格和物品外观。本文介绍插件的默认玩法，实际内容请以游戏内的物品名称和说明为准。

## 快速开始

1. 在大厅右键“选择游戏”，加入一张等待中的地图。
2. 开局后在出生岛收集铁锭和金锭。
3. 右键物品商店 NPC，购买方块、武器、工具和道具。
4. 用方块保护床并搭路，前往钻石岛或地图中心收集高级资源。
5. 破坏敌方床，再将该队玩家全部淘汰。

## 资源与商店

| 资源 | 主要用途 |
| --- | --- |
| 铁锭、金锭 | 在物品商店购买常用方块、武器、工具和道具 |
| 钻石 | 在团队升级 NPC 处购买全队共享的升级和陷阱 |
| 绿宝石 | 购买钻石装备、药水、末影珍珠等高级物品 |

右键物品商店 NPC 打开商店：

| 操作 | 效果 |
| --- | --- |
| 点击商品 | 购买一次 |
| `Shift + 右键`商品 | 尽量购买当前资源能够支付的最大数量 |
| `Shift + 左键`商品 | 添加到快捷购买栏，或从快捷购买栏移除 |

永久护甲、多级工具、免费商品和部分特殊商品不会重复批量购买。价格不足时，商店会显示还缺少多少资源。

## 基础物品

| 物品 | 使用方法 |
| --- | --- |
| 羊毛 | 右键放置，用于快速搭路；购买后会变为本队颜色 |
| 硬化粘土、末地石、原木、黑曜石 | 右键放置，用于分层保护床 |
| 防爆玻璃 | 右键放置，可以抵抗爆炸，适合搭配其他防御方块 |
| 梯子 | 放在方块侧面，用于攀爬，也可干扰敌人贴近床防 |
| 剑、击退木棍 | 左键攻击；击退木棍适合把桥上的敌人打入虚空 |
| 弓和箭 | 按住右键蓄力，松开后射击远处或桥上的敌人 |
| 剪刀 | 快速破坏羊毛；购买后死亡仍会保留 |
| 镐 | 适合破坏末地石、玻璃和黑曜石；可逐级升级，死亡后降低一级，最低级不会继续下降 |
| 斧 | 适合破坏木质床防；可逐级升级，死亡后降低一级，最低级不会继续下降 |
| 锁链、铁、钻石护甲 | 购买后自动替换护腿和靴子，死亡后仍会保留；本队颜色的头盔和胸甲不会被替换 |
| 金苹果 | 按住右键食用，恢复状态并获得额外生命保护 |
| 速度、跳跃、隐身药水 | 按住右键饮用；隐身受到伤害后会解除 |

地图原有方块通常不能破坏，本局中由玩家放置的方块可以破坏。

## 特殊道具

| 道具 | 使用方法 |
| --- | --- |
| 火球 | 右键向准星方向发射，可炸开玩家放置的方块并击退玩家；潜行时发射速度和后坐力更强，可用于火球跳 |
| TNT | 像方块一样放置，落地后自动点燃；适合炸开床防或击退附近玩家 |
| 末影珍珠 | 右键投掷，落点有效时会传送过去；进攻前注意落点和虚空 |
| 搭桥蛋 | 右键投掷，飞行轨迹下方会连续生成本队颜色的羊毛桥 |
| 蠹虫 | 默认以雪球形式投掷，在落点召唤一只限时作战的蠹虫，用于追击和干扰敌人 |
| 梦境守卫者 | 对方块右键放置，召唤限时作战的铁傀儡，适合守家或封锁入口 |
| 水桶 | 右键放水，可减速敌人、缓冲坠落，并保护床防免受部分爆炸破坏 |
| 海绵 | 放进水中吸走附近的水，适合快速清除敌方水防 |
| 魔法牛奶 | 按住右键饮用，默认在接下来的 60 秒内不会触发敌方陷阱 |
| 袖珍弹出塔 | 对地面右键放置，按你的朝向自动生成一座带梯子的本队颜色防御塔；周围需要留出空间 |
| 回城卷轴 | 右键使用后等待 5 秒，传送到本队出生点；引导期间会显示每秒倒计时和附近玩家可见的蓝色粒子，不能同时使用第二个卷轴 |

蠹虫、铁傀儡的持续时间以及火球的伤害、击退和冷却都可由服务器调整。

## 团队箱子

手持资源或道具，对本队岛屿的箱子按 `Shift + 左键`，可以把主手物品快速存入箱子。箱子装不下时，剩余物品会留在手中；永久装备和出生物品不会被存入。

## 死亡后会保留什么

- 永久护甲和剪刀会保留。
- 镐和斧会降低一级，但不会低于最低级。
- 普通武器、方块、资源和消耗型道具需要重新收集或购买。
- 以死亡瞬间的床状态判定：床仍存在时会在倒计时后复活，即使倒计时期间床被破坏；床已被破坏时死亡会进入旁观状态。

## 大厅与旁观物品

大厅物品通常右键使用：玩家头用于查看战绩，箱子用于选择游戏，红床用于离开当前地图并返回大厅。物品位置和外观可能被服务器修改。

被淘汰后，右键“传送”物品可选择仍在游戏中的玩家进行观察；右键“返回大厅”物品可离开本局。进入第一人称观察后，按潜行键退出。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/bw gui` | 打开游戏选择菜单 |
| `/bw leave` 或 `/leave` | 离开当前游戏 |
| `/bw highlight` | 开关当前对局的队友高光；队友离场或对局结束后自动清理，发光状态对所有玩家可见 |
| `/rejoin` | 在服务器允许的重连时间内返回掉线前的游戏 |
