# SimpMC-BedWars 玩家完整指南

这是一份只面向普通玩家的游玩说明。你不需要了解插件安装、配置文件或竞技场设置，也不需要管理员权限。

文中的 `<玩家>`、`<竞技场>` 等内容需要替换成实际名称，输入时不要保留尖括号。例如：`/bw invite Steve`。

> 不同服务器可以调整地图、商品价格、资源速度、倒计时和部分功能权限。如果游戏内显示与本文不同，以当前服务器的实际设置为准。

## 一分钟快速入门

第一次游玩时，记住下面六件事就够了：

1. 在主大厅右键“选择游戏”，选择一张尚未开始的地图；也可以输入 `/bw gui`。
2. 开局后先收集出生岛上的铁锭和金锭，在商店购买羊毛、武器与工具。
3. 保护本队的床，同时搭路前往其他岛屿并破坏敌方床。
4. 本队床还在时，死亡后可以复活；床被破坏后再次死亡会被最终淘汰。
5. 钻石主要用于队伍升级，绿宝石通常用于购买更强的个人装备。
6. 最后一支仍有玩家存活的队伍获胜。

## 主大厅

### 大厅中的状态

进入 BedWars 主大厅后，你会被切换为冒险模式。大厅中不能 PvP，也不能挖掘、放置、合成、穿戴或随意移动和丢弃插件发放的大厅物品。重新进入大厅时，物品栏会恢复为服务器设置的大厅物品。

大厅通常会提供三件物品：

| 默认位置 | 默认物品 | 使用方式 | 作用 |
| --- | --- | --- | --- |
| 快捷栏第 1 格 | 历史战绩 | 右键 | 查看胜场、击杀、最终击杀、破坏床等数据 |
| 快捷栏第 5 格 | 选择游戏 | 右键 | 打开竞技场选择菜单 |
| 快捷栏第 9 格 | 回到主大厅 | 右键 | 返回代理网络中的总大厅服务器 |

服主可以修改物品名称、材质和位置，因此不要只凭物品外观判断功能。若物品缺失，重新进入大厅通常会自动补齐。

“回到主大厅”与“返回 BedWars 大厅”不是同一个操作：

- 主大厅中的“回到主大厅”会尝试切换到 BungeeCord 或 Velocity 网络配置的总大厅。
- 等待区和旁观区中的红床只会让你离开当前竞技场，回到本服的 BedWars 大厅。
- 如果当前服务器没有接入代理，或代理大厅名称配置错误，插件会提示无法切换服务器。此时请联系服主。

### 大厅消息

玩家进入或离开 BedWars 主大厅时，大厅内的玩家会看到：

```text
[BW] 玩家 Steve 加入了游戏
[BW] 玩家 Steve 离开了游戏
```

这些消息只发送给当时位于大厅的玩家，不会打扰正在游戏中的玩家。

## 加入与离开竞技场

### 加入方法

你可以通过以下方式加入一场游戏：

- 右键大厅中的“选择游戏”。
- 输入 `/bw gui` 打开竞技场选择菜单。
- 输入 `/bw join <竞技场>` 加入指定竞技场。
- 输入 `/bw join random` 随机加入可用竞技场。
- 点击服务器提供的加入告示牌或 NPC。
- 接受等待区玩家发来的竞技场邀请。

竞技场一般有以下状态：

| 状态 | 含义 |
| --- | --- |
| 等待中 | 可以加入，正在等待足够玩家 |
| 即将开始 | 倒计时已经开始，通常仍可加入 |
| 游戏中 | 对局已经开始，不能作为参赛者中途加入 |
| 重置中或不可用 | 地图正在恢复或已被管理员关闭，暂时不能加入 |

玩家加入一张等待中的地图时，大厅玩家和该竞技场内的等待玩家会看到加入提示：

```text
[BW] 玩家 Steve 加入了竞技场 Acropolis
```

对局开始后不会继续播报这种匹配提示。

### 离开方法

- 在等待区或旁观区右键“返回大厅”红床。
- 输入 `/bw leave`。
- 输入 `/leave`。

离开正在进行的对局可能会被计为失败，也会影响队友，请在确认不再继续游戏时使用。

## 开局前邀请与组队

插件把“邀请进入竞技场”和“邀请成为队友”分成两个步骤。它们用途不同。

### 邀请大厅玩家进入当前竞技场

你必须已经处于一张尚未开始的竞技场中，然后输入：

```text
/bw invite <玩家>
```

被邀请者必须在线并且仍在主大厅。邀请有效期为 30 秒，被邀请者可以直接点击聊天中的“接受”或“拒绝”。

其他相关命令：

```text
/bw invite list
/bw invite accept <邀请者>
/bw invite decline <邀请者>
```

接受这个邀请只代表进入同一张竞技场，不自动保证双方属于同一队。想要成为队友，还需要使用下一节的开局组队功能。

### 在当前对局中固定队友

双方都进入同一张等待中的竞技场后，使用：

```text
/bw team invite <玩家>
```

收到邀请后可以点击聊天按钮，也可以手动输入：

```text
/bw team accept <邀请者>
/bw team decline <邀请者>
```

完整的本局组队命令如下：

| 命令 | 作用 |
| --- | --- |
| `/bw team` 或 `/bw team list` | 查看当前开局队伍、队长和可邀请玩家 |
| `/bw team invite <玩家>` | 队长邀请同一竞技场中的玩家成为队友 |
| `/bw team accept <邀请者>` | 接受邀请 |
| `/bw team decline <邀请者>` | 拒绝邀请 |
| `/bw team leave` | 退出当前开局队伍，回到单人分配状态 |

开局队伍人数不能超过该地图每队人数上限。只有队长能继续邀请成员，邀请同样会在 30 秒后过期。单人队地图无需使用这组命令。

匹配开始时，插件会优先保持已经确认的开局队伍；没有组队的玩家会先作为单人组，再被随机分配到仍有空位的队伍。普通开局会保证至少存在两支非空队伍，不会把所有玩家塞进唯一一队。

### `/party` 与 `/bw team` 的区别

部分服务器会启用内置 `/party` 或接入其他组队插件。`/party` 更适合建立跨大厅、跨多局维持的玩家小队；`/bw team` 只影响当前等待中的这一局，并且结果更直接。

常见内置 Party 命令：

```text
/party invite <玩家>
/party accept <邀请者>
/party info
/party leave
/party remove <玩家>
/party promote <玩家>
/party disband
```

如果服务器关闭了内置 Party，请直接使用 `/bw invite` 和 `/bw team`。

## 胜利目标与队伍

### 床的作用

每支队伍都有一张床：

- 床未被破坏：队员死亡后可以复活。
- 床被破坏：该队队员失去复活机会，之后的死亡是最终死亡。
- 队伍所有成员都最终死亡：该队被淘汰。
- 最后一支仍有成员存活的队伍获胜。

开局后通常应该先用羊毛或更坚固的方块保护床，再决定进攻路线。仅堆一层同类方块容易被对应工具快速拆除，混合不同方块能迫使敌人准备多种工具。

### 队伍颜色

队伍名称保留地图设置的原始名称，不会为了中文显示而翻译。皮革护甲、购买的羊毛、玩家名颜色和部分界面会使用队伍颜色。

颜色会严格区分，例如：

- Green 与 Dark Green 是不同颜色。
- Gray 与 Dark Gray 是不同颜色。
- Cyan 使用青色羊毛，不会被当作浅蓝色羊毛。

开局时玩家会获得本队颜色的皮革护甲。服主可以决定商店中的永久护甲升级是只替换护腿和靴子，还是提供头盔、胸甲、护腿和靴子全套；以商品说明和实际穿戴结果为准。

## 资源、商店与队伍升级

### 资源类型

| 资源 | 常见位置 | 常见用途 |
| --- | --- | --- |
| 铁锭 | 队伍出生岛 | 羊毛、基础方块、基础武器、工具和常用道具 |
| 金锭 | 队伍出生岛 | 更好的武器、工具、护甲或高价值道具 |
| 钻石 | 地图外岛 | 为全队购买锋利、保护、急迫、陷阱等升级 |
| 绿宝石 | 地图中心 | 购买最高级个人装备和强力道具 |

资源价格和刷新速度由服务器配置决定。地图事件可能在游戏进行一段时间后提升钻石或绿宝石生成器等级。

### 物品商店

右键商店 NPC 打开物品商店。常见分类包括方块、近战武器、护甲、工具、远程武器、药水与实用道具。

购买操作：

- 普通左键或右键商品：购买一次。
- Shift + 右键普通商品：使用背包内对应货币，购买当前可负担的最大完整数量。
- Shift + 左键商品：添加到或移出“快速购买”栏，不是批量购买。

批量购买只适用于能够重复购买的普通货币商品。永久升级、多级工具、命令商品、免费商品以及使用 Vault 金币的商品每次仍只处理一次，防止重复扣款或购买无意义的多份升级。

购买前请确认背包有足够空位。如果最多只能放下一部分商品，实际购买量可能受到背包容量限制。

### 快速购买

快速购买页用于保存你最常买的商品位置：

1. 打开商品分类。
2. 对想保存的商品按 Shift + 左键。
3. 点击一个空的快速购买槽位。
4. 以后打开商店首页即可快速购买。

在快速购买页对已有商品按 Shift + 左键，可以把它从快捷栏移除。

### 队伍升级

右键队伍升级 NPC，可以用钻石购买对全队生效的强化。升级项目由服务器决定，常见项目包括：

- 武器锋利。
- 护甲保护。
- 挖掘急迫。
- 资源熔炉升级。
- 治疗池。
- 岛屿陷阱。

这是团队共享消费。购买前可以先在队伍聊天中沟通，避免多人同时攒同一种升级。

### 本队箱子快速存入

对本队岛屿附近的普通箱子按 Shift + 左键，会把主手中的物品直接存入箱子：

- 只处理主手物品，不会清空整个背包。
- 箱子空间不足时，只存入能够容纳的数量，剩余物品仍留在手上。
- 永久装备和插件发放的出生物品不会被存入。
- 该功能只适用于本队箱子，不能远程整理其他队伍的箱子。

## 建造、方块与战斗

### 玩家放置方块

竞技场会记录本局由玩家放置的方块。通常只有这些方块可以被玩家破坏，地图原有结构受到保护。这意味着：

- 自己、队友和敌人在本局放置的防御方块通常都可破坏。
- 地图装饰和岛屿主体通常不可破坏。
- 游戏结束后，玩家放置的方块会随地图重置而清除。

NPC 周围约 1 格范围禁止放置方块，防止商店或升级 NPC 被堵住。放置操作会被撤销，物品不会被正常消耗。竞技场设置人员不受这条普通对局限制。

### 火球、TNT 与火焰

火球和 TNT 可用于破坏玩家放置的防御、击退敌人或进行跳跃。插件对爆炸范围、击退、伤害和冷却做了 BedWars 化处理，实际强度可能由服主调整。

火势不会自然蔓延，以免一处火焰无限烧毁地图。不要依赖原版火焰扩散来拆除大面积防御，直接使用工具或爆炸物更可靠。

### 特殊道具

服务器可能在商店提供以下道具：

- 桥蛋：飞行时沿途铺设队伍颜色的羊毛。
- 袖珍弹出塔：在合适空间内自动生成带队伍颜色方块和梯子的防御塔。
- 梦境守护者或蠹虫：召唤限时协助作战的生物。
- 追踪指南针、药水、海绵等其他实用物品。

自动建筑需要足够空间。附近有地图结构、玩家方块或高度不足时，生成结果可能受限。

## 死亡、复活与淘汰

### 床仍存在时

你死亡后会进入临时旁观状态并等待复活：

- 非虚空死亡：在死亡位置原地进入旁观状态。
- 掉入虚空死亡：回到本队出生点附近等待复活。
- 临时旁观期间不能移动、拾取或操作物品，也不会挡住其他玩家。
- 倒计时结束后，在本队出生点复活。

如果出生点被方块遮挡，插件会寻找附近安全位置。两格高空间可以正常站立；只有一格高但允许趴下的空间也会被视为可用位置。

主动走入虚空且最近没有敌方有效击退时，聊天会显示“某玩家自走虚空”；如果近期被敌人击中，则仍可能把击杀归给该敌人。

### 床已被破坏时

床被破坏后再次死亡会被最终淘汰。你会成为整局旁观者，不能继续参与战斗。TAB 中可能显示：

```text
[已淘汰] Steve
```

其中玩家名仍使用原队伍颜色。旁观者不会在 TAB 中显示生命值。

### 旁观操作

旁观时通常会得到：

- “传送”物品：右键打开仍在竞技场中的玩家列表并传送观察。
- “回到大厅”红床：右键离开本局。

旁观者对参赛玩家不可见，也不能捡起物品、破坏或放置方块、攻击玩家或干扰比赛。

### 背包与末影箱

每局开始和状态重置时，插件会直接删除上一局遗留的背包与末影箱内容，再发放本局物品。不要把需要长期保存的生存服物品带进 BedWars；本模式不把竞技场背包当作永久仓库。

## 聊天频道

聊天格式会用白色的 `>` 分隔名字与消息，消息正文默认显示为灰色，以免和系统提示混淆。

### 等待阶段

竞技场尚未开始时，普通聊天会发送给当前等待区玩家。

### 游戏阶段

开局时本队有两名或更多玩家：

- 普通聊天只发送给队友。
- 输入 `/shout <消息>` 可以向当前竞技场所有参赛者和旁观者喊话。
- 也可以在消息开头加 `!`，例如 `!中路有人`。
- 全场喊话通常需要 `bw.shout` 权限，并可能有冷却时间。

开局时本队只有一名玩家：

- 普通聊天自动发送到当前竞技场公屏。
- 不需要 `/shout` 权限，也不进入喊话冷却。
- 这个判断在开局时固定。队友开局后掉线、重连或被淘汰，不会让聊天频道中途改变。

### 旁观聊天

被淘汰的旁观玩家通常只能与其他旁观者交流，不能把战况直接透露给仍在比赛中的队伍。

如果服务器给你 `bw.chatcolor` 权限，可以在消息中使用 `&` 颜色代码；普通玩家默认没有该权限。

## 掉线与重连

玩家意外断线后，默认有 30 秒重连窗口。服务器可以调整这个时间。

- 在窗口内重新连接，并使用 `/rejoin`，可以尝试回到仍在进行的对局。
- `/rejoin` 可能需要服主授予 `bw.rejoin` 权限。
- 超过窗口仍未回来，会被直接视为离开竞技场。
- 竞技场已经结束、被禁用或进入重置后，不能再重连到该局。
- 正常结束后的地图重置会先把玩家送回大厅，不应把仍在线的玩家踢出服务器。

如果你只是暂时网络波动，不要立即加入另一张地图；先尝试 `/rejoin`。

## TAB、侧边栏与提示信息

### 游戏 TAB

游戏中的 TAB 玩家列表用于快速辨认队伍和状态：

- 玩家名本身使用队伍颜色，名字前不会重复添加队伍名称。
- 同一队伍的玩家会放在一起，并按玩家名字典序排列。
- 队友会使用更醒目的颜色提示。
- 被淘汰玩家会带有灰色括号和红色“已淘汰”标记。
- 旁观玩家不显示生命值。
- 原版信号格表示网络延迟；服务器不会额外再显示一个容易混淆的第二 Ping 数字。

大厅 TAB 的页首文字可能由服务器自定义，因此不同服务器看到的标题、在线人数或网站地址可能不同。

### 侧边栏

右侧侧边栏通常显示：

- 地图、模式和玩家数。
- 下一个事件及倒计时。
- 各队床是否存在、队伍是否被淘汰。
- 你的击杀、最终击杀或床数等本局数据。

如果一支队伍在开局瞬间就是空队，它不会出现在本局侧边栏中。这样可以避免地图配置了很多队伍、实际却无人使用时占满界面。

### 系统提示

常见提示包括：

- 床被破坏。
- 队伍被淘汰。
- 资源生成器升级。
- 所有床自动销毁。
- 绝杀或游戏结束。

不要把玩家聊天误认为系统消息：玩家消息的名字与正文之间会有明确的 `>` 分隔符。

## 游戏结束与地图重置

产生胜者后会显示本局结果和统计。竞技场随后进入重置倒计时。

默认情况下，聊天栏会在以下剩余秒数广播重置提示：

```text
60、30、15、10、5、4、3、2、1、0
```

倒计时不会每秒刷屏。到 0 秒后，插件先把竞技场中的玩家安全送回大厅，再卸载并恢复地图。地图重新可用前，在竞技场选择菜单中可能显示重置中或暂不可加入。

## 玩家命令速查

主命令可以使用 `/bw`，也支持 `/bedwars`、`/simpmcbedwars` 和 `/simpmcbw` 等别名。

### 基础命令

| 命令 | 作用 | 默认权限要求 |
| --- | --- | --- |
| `/bw`、`/bw cmds` | 查看可用命令 | 无 |
| `/bw gui [分组+分组]` | 打开竞技场选择菜单 | 无 |
| `/bw join <竞技场/分组/random>` | 加入竞技场 | 无 |
| `/bw arenaList` | 查看竞技场列表 | 无 |
| `/bw leave`、`/leave` | 离开当前竞技场 | 无 |
| `/bw stats` | 查看历史战绩 | 无 |
| `/bw lang <语言代码>` | 切换个人语言 | 无 |
| `/bw invite ...` | 邀请大厅玩家加入当前等待竞技场 | 无 |
| `/bw team ...` | 管理本局开局队伍 | 无 |
| `/bw teleporter` | 打开旁观传送菜单 | 无 |
| `/bw upgradesmenu` | 打开本队升级菜单 | 无，但必须处于有效队伍中 |
| `/party ...` | 使用内置组队系统 | 无，且服务器需启用 |
| `/shout <消息>`、`!消息` | 游戏内全场喊话 | `bw.shout` |
| `/rejoin` | 在有效窗口内重连 | `bw.rejoin` |

“无”表示插件按照官方权限规则不要求额外权限节点，但服主仍可以通过其他权限或命令插件限制使用。

`bw.player` 是为旧版权限配置保留的兼容集合，不是基础玩家命令的前置条件，也不会自动授予 `/shout` 或 `/rejoin`。

## 常见问题

### 为什么我不能在大厅丢弃或移动物品？

这是大厅保护机制。大厅物品是功能按钮，不是普通生存物品。进入竞技场或离开大厅后，插件会按当前阶段重新整理物品栏。

### 为什么“回到主大厅”提示失败？

这件物品需要服务器通过 BungeeCord 或 Velocity 代理连接，并且代理中存在服主配置的大厅服务器名称。玩家无法在客户端修复，请把具体错误提示发给服主。

### 为什么 `/bw invite` 找不到朋友？

邀请者必须位于尚未开始的竞技场，被邀请者必须位于主大厅。朋友如果已经进入其他竞技场、正在设置地图或离线，就不能接受邀请。

### 为什么接受竞技场邀请后没有和朋友同队？

`/bw invite` 只负责让朋友进入同一张地图。双方进入等待区后，还要使用 `/bw team invite <玩家>` 并接受，才能固定为本局队友。

### 为什么我不能使用 `/shout` 或 `/rejoin`？

这两个功能默认分别需要 `bw.shout` 和 `bw.rejoin` 权限。请联系服主或查看服务器商店、等级规则；插件不会通过 `bw.player` 自动授予它们。

### 为什么死后没有回到出生岛？

非虚空死亡会先在原地进入临时旁观状态；虚空死亡才会回到本队出生点附近等待。复活倒计时结束后才正式回到可战斗状态。

### 为什么出生点位置和地图标记略有偏移？

出生点会使用方块中心，避免玩家卡在边缘；同时保留地图设置的朝向。若中心位置被堵住，插件会改用附近的安全位置。

### 为什么破坏不了地图方块？

BedWars 只允许破坏本局由玩家放置、且规则允许破坏的方块。地图原有主体受保护，这是正常机制。

### 为什么商店中的护甲只换了两件，或一次换了四件？

这是服务器级选项。服主可以选择永久护甲只出售护腿和靴子，也可以选择出售全身四件套。

### 为什么商店中某个特殊物品显示异常或无法购买？

先关闭并重新打开商店，确认客户端使用服务器支持的 Minecraft 版本。如果仍然出现物品名缺失、材质错误或购买失败，请截图商品说明并把服务器版本、插件版本和操作步骤发给服主。

## 实用技巧

- 开局先观察每队人数和地图布局，再决定快攻、守床或抢占资源岛。
- 单排时也可以使用 `/bw team list` 查看可邀请玩家；若本队上限为 1，则无需组队。
- 把羊毛、工具、火球等高频商品加入快速购买，能显著减少站在商店前的时间。
- 购买大量羊毛或方块时使用 Shift + 右键，但先给武器和关键道具预留背包空间。
- 钻石是全队资源。准备购买升级时，可以使用队伍聊天告知队友。
- 回岛后用 Shift + 左键点击本队箱子快速存入主手资源，减少整理背包的时间。
- 床被破坏后优先保命；没有床时，每一次换血和虚空搭路都可能导致最终淘汰。
- 断线重连窗口有限。重新连接后尽快输入 `/rejoin`，不要等待到超时。
- 游戏结束后等待插件自动送回大厅，不要在地图重置的最后几秒反复执行传送命令。

如果你发现可稳定复现的问题，请向服主提供：插件版本、Paper 版本、竞技场名称、发生时间、完整报错或截图，以及从进服到触发问题的操作步骤。信息越完整，问题越容易被准确修复。
