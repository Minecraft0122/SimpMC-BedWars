# SimpMC-BedWars 玩家使用说明

这份说明只介绍游戏里的物品和功能怎么使用。不同服务器可能调整商品价格、资源速度和物品位置，请以游戏内显示为准。

## 快速开始

1. 在大厅右键“选择游戏”，加入一张等待中的地图。
2. 开局后收集出生岛上的铁锭和金锭。
3. 右键商店 NPC，购买羊毛、武器、工具和道具。
4. 用方块保护本队床，再搭路破坏其他队伍的床。
5. 床还在时可以复活；床被破坏后再次死亡会被淘汰。
6. 最后一支仍有玩家存活的队伍获胜。

## 大厅物品

| 默认位置 | 物品 | 用法 |
| --- | --- | --- |
| 第 1 格 | 历史战绩 | 右键查看胜场、击杀和破坏床等数据 |
| 第 5 格 | 选择游戏 | 右键打开竞技场列表 |
| 第 9 格 | 回到主大厅 | 右键返回服务器网络的总大厅 |

服主可以修改物品位置和外观。大厅物品不能随意移动或丢弃，重新进入大厅时会自动补齐。

等待区和旁观区里的“返回大厅”红床用于离开当前竞技场，返回 BedWars 大厅。

## 加入和离开游戏

加入游戏：

- 右键大厅中的“选择游戏”。
- 输入 `/bw gui` 打开选择菜单；地图超过一页时使用底部箭头翻页。
- 输入 `/bw join <竞技场>` 加入指定地图。
- 输入 `/bw join random` 随机匹配。
- 点击服务器提供的加入 NPC 或告示牌。

离开游戏：

- 右键等待区或旁观区的“返回大厅”红床。
- 输入 `/bw leave` 或 `/leave`。

## 邀请朋友

### 邀请朋友进入同一张地图

你先加入一张尚未开始的竞技场，然后输入：

```text
/bw invite <玩家>
```

朋友必须仍在大厅。邀请有效期为 30 秒，对方可以直接点击聊天中的“接受”。

`/bw invite` 只负责让朋友加入同一张地图，不保证同队。

### 选择游戏队伍并邀请固定队友

进入等待中的地图后，输入：

```text
/bw team
```

插件会打开游戏队伍选择 GUI。点击队伍颜色即可预选红队、蓝队等地图中真实存在的队伍；也可以取消选择并交给系统自动均衡。预选是尽量满足的偏好，若固定队友的选择互相冲突，或选择组合无法满足每队人数上下限，开局时会优先保证合法分队。

需要邀请固定队友时使用 `/bw team squad` 打开组队邀请 GUI。点击玩家头像发送邀请；收到邀请时，绿色头像左键接受、右键拒绝。对方也可以点击聊天中的“接受”，开局时会优先把你们分到同一队。

常用组队指令：

| 指令 | 用法 |
| --- | --- |
| `/bw team`、`/bw team select` | 打开游戏队伍选择 GUI |
| `/bw team choose <队伍>` | 不打开 GUI，直接预选指定游戏队伍 |
| `/bw team clear` | 取消游戏队伍预选 |
| `/bw team squad` | 打开固定队友邀请 GUI |
| `/bw team invite <玩家>` | 邀请玩家成为本局队友 |
| `/bw team accept <玩家>` | 接受邀请 |
| `/bw team decline <玩家>` | 拒绝邀请 |
| `/bw team leave` | 退出开局队伍 |

没有预选队伍的玩家会在开局时随机且尽量均衡地分散到更多合法队伍。已经组好的固定队友不会为了凑出对手而被拆开：至少存在两支都满足地图开局人数下限的队伍后才会进入倒计时。单人队地图仍可选择游戏队伍，但不需要邀请固定队友。

## 资源怎么用

| 资源 | 主要用途 |
| --- | --- |
| 铁锭 | 羊毛、基础方块、基础武器和常用道具 |
| 金锭 | 更好的武器、工具、护甲和道具 |
| 钻石 | 在队伍升级 NPC 处购买全队升级 |
| 绿宝石 | 购买高级装备、药水和强力道具 |

铁锭和金锭通常在本队出生岛生成；钻石在外岛生成；绿宝石通常在地图中心生成。

## 商店怎么用

右键商店 NPC 打开商店。

| 操作 | 效果 |
| --- | --- |
| 普通点击商品 | 购买一次 |
| Shift + 右键商品 | 用背包内对应货币购买当前能买到的最大数量 |
| Shift + 左键商品 | 添加到或移出快速购买栏 |

永久护甲、多级工具、免费商品和部分特殊商品不会被重复批量购买。

商店护甲固定只替换护腿和靴子；本队颜色的皮革头盔与胸甲会一直保留。

### 快速购买

1. 打开商品分类。
2. 对商品按 Shift + 左键。
3. 选择一个空的快速购买槽位。
4. 以后可以直接从商店首页购买。

## 队伍升级怎么用

右键队伍升级 NPC，用钻石购买全队共享的升级。常见升级包括：

- 武器锋利 I–IV，必须逐级购买；默认价格为 2、4、8、14 钻石。
- 护甲保护。
- 挖掘急迫。
- 资源生成速度。
- 治疗池。
- 岛屿陷阱。

升级对整支队伍生效，购买前最好和队友沟通。

## 本队箱子快捷存入

手持要存入的物品，对本队箱子按 Shift + 左键：

- 主手物品会自动存入箱子。
- 箱子空间不足时，剩余物品仍留在手上。
- 永久装备和出生物品不会被存入。

这个操作只存主手物品，不会清空整个背包。

## 常用特殊道具

| 道具 | 用法 |
| --- | --- |
| 火球 | 右键发射，可破坏玩家方块、击退玩家或进行火球跳；每次发射会随机获得 200–300 格的最大飞行距离；按住潜行键投掷会从约 1.6 加速到 2.4 格/tick，并把自己轻微向后推约半格 |
| TNT | 放置后自动点燃，用于炸开床防御或击退玩家 |
| 桥蛋 | 投掷后沿飞行路线铺设本队颜色的羊毛 |
| 袖珍弹出塔 | 在有足够空间的位置放置，自动生成防御塔和梯子 |
| 梦境守护者/蠹虫 | 投掷或放置后召唤限时战斗生物 |
| 指南针 | 用于追踪仍在游戏中的敌人 |

弹出塔附近如果空间不足，可能无法完整生成。火势不会自然蔓延。火球的 200–300 格是按实际路径累计的随机最大射程，不会穿过碰撞物，也不会强制加载远处区块；沿途区块未加载时可能提前停止。

## 方块和床

- 地图原有方块通常不能破坏。
- 本局由玩家成功放置的方块可以正常破坏，即使它位于出生保护等地图保护区域内；被其他插件取消的放置不会被误记为玩家方块。
- NPC 附近约 1 格内不能放置方块，避免堵住商店。
- 本队床存在时，死亡后可以复活。
- 本队床被破坏后，再次死亡会被最终淘汰。

购买的羊毛会使用本队颜色。Green、Dark Green、Gray、Dark Gray 等颜色互不混用，Cyan 队使用青色羊毛。

## 死亡和旁观

床仍存在时：

- 普通死亡会在死亡位置进入临时旁观状态。
- 掉入虚空会回到本队出生点附近等待复活。
- 倒计时结束后在本队出生点复活。
- 出生点被堵住时，会使用附近的安全位置；可以趴下的空间也算安全。

床已被破坏时，死亡后会成为旁观者：

- 右键“传送”物品可以选择玩家进行观察。
- 右键“回到大厅”红床可以离开本局。
- 旁观者不能捡物品、攻击、放方块或干扰比赛。

每局都会删除上一局遗留的背包和末影箱内容，不要把需要保存的物品带入 BedWars。

## 聊天怎么用

游戏中的玩家消息使用白色 `>` 分隔名字和正文，消息正文为灰色。

开局时本队有两人或更多玩家：

- 普通聊天只发送给队友。
- `/shout <消息>` 向整个竞技场喊话。
- 也可以发送 `!消息` 进行全场喊话。

开局时本队只有一名玩家：

- 普通聊天会直接发送到竞技场公屏。
- 不需要使用 `/shout`。

`/shout` 和 `!消息` 默认对普通玩家开放且没有插件冷却；服务器仍可通过权限插件显式撤销 `bw.shout`。

## 掉线重连

意外掉线后，默认有 30 秒重连时间。重新进入服务器后输入：

```text
/rejoin
```

超过重连时间会被视为离开游戏。被服务器命令、封禁或反作弊踢出时会立即放弃本局，不保留重连资格；普通网络断开和超时仍使用上述重连窗口。服务器可能要求 `bw.rejoin` 权限，也可能修改重连时间。

## TAB 和侧边栏

- TAB 不再在玩家名前重复显示队伍名称或队伍字母，只用所属队伍颜色渲染玩家名；头顶名牌使用同一队伍颜色。
- 队伍按红、黄、绿、深绿、青、蓝、粉的光谱顺序排列，白、灰、深灰排在后面。
- 同队玩家会排在一起，并按完整玩家名字典序排列。
- 最终淘汰者和纯旁观者在 TAB 中使用原版观察者模式样式；淘汰者仍留在原队伍分组并保留原队颜色，纯旁观者排在最后。
- 游戏进行时，存活玩家、已淘汰玩家和旁观者都会在 TAB 页首看到从 `00:00` 开始累计的本局时间。
- 旁观玩家不会显示生命值。
- 侧边栏会显示地图事件、队伍床状态和倒计时。
- 开局时没有玩家的队伍不会占用侧边栏位置。

## 游戏结束

游戏结束后，聊天栏会在以下时间提示竞技场重置倒计时：

```text
60、30、15、10、5、4、3、2、1、0
```

倒计时结束后，玩家会被送回大厅，地图随后自动恢复。

## 常用指令

| 指令 | 作用 |
| --- | --- |
| `/bw gui` | 打开竞技场选择菜单 |
| `/bw join <竞技场>` | 加入指定竞技场 |
| `/bw join random` | 随机加入竞技场 |
| `/bw leave` | 离开当前竞技场 |
| `/bw stats` | 查看历史战绩 |
| `/bw lang <语言代码>` | 切换个人语言 |
| `/bw invite <玩家>` | 邀请大厅玩家进入当前竞技场 |
| `/bw team` | 打开本局游戏队伍选择 GUI |
| `/bw team squad` | 打开本局固定队友邀请 GUI |
| `/bw team invite <玩家>` | 邀请玩家成为本局队友 |
| `/bw teleporter` | 打开旁观传送菜单 |
| `/shout <消息>` | 向整个竞技场发送消息 |
| `/rejoin` | 在有效时间内重新加入断线前的游戏 |

如果某项功能无法使用，请先阅读游戏内提示；权限、商品和倒计时都可能由当前服务器单独调整。
